const 修饰的变量是常量,更准确的来说,是只读变量。因为它存放在栈中而不是静态内存中。  
所以在C语言中,不能用 const 变量来指定静态数组的长度 。

> C标准中,静态数组的长度要在编译时确定，从 C99 开始支持变长数组 VLA，也即局部数组的大小可以是运行时常量。

在C++中，const 修饰的变量如果在局部作用域（例如函数中）或使用 constexpr 修饰时，会被编译器视为编译期常量。因为C++对const的增强处理，使它成为真正的不可变值。

- C语言中的const变量: 只读变量，有自己的存储空间
- C++中的const常量: 可能分配存储空间,也可能不分配存储空间；
  - 当const常量为全局，并且需要在其它文件中使用，会分配存储空间；
  - 当使用&操作符，取const常量的地址时，会分配存储空间；
  - 当const int &a = 10; const修饰引用时，也会分配存储空间。

**const 优先左结合而后右结合**，意味着const若是左边有值（类型或指针）则与左边值结合，若是左边没有值则再与右边值结合。

---
#### 指向常量的指针 ( pointer to const )

`const int *` 或 `int const *`，`const`修饰的是类型`int`，即指针指向的内容是常量。

1. 指向常量的指针不能改变它所指向的对象的值  
   下例中，cptr 指向 pi, 但不能通过cptr 改变 pi 的值

```cpp
double pi = 3.14
const double *cptr = &pi 
```

2. 存放常量对象的地址，只能使用指向常量的指针
```cpp
const double pi = 3.14;
double *ptr = &pi;  // 错误，普通的指针不能存放常量对象的地址
const double *ptr = &pi; // 正确，指向常量的指针可以存放常量对象的地址
```
很容易想通：常量对象的值不能改变，如果用普通的指针存放常量对象的地址，就有可能改变常量对象的值，所以规定只能使用指向常量的指针存放常量对象的地址。

---
#### 指针常量 ( const pointer)
`int *const`中，`const`修饰的是指针`*`,也即指针是常量，指针的指向不能修改。

---
#### 常量成员函数

使用const修饰的类的成员函数

```cpp
class Test{
    int value;
    int get_value () const {return value}; //常量成员函数
}
```

const 的作用是修改隐式 this 指针的类型,从普通的指针变为指向常量的指针。普通成员函数隐式的this指针的声明是 `Test *this`; 常量成员函数的this指针类型是 `const Test *this`;

也正因如此，常量成员函数内不能修改调用常量成员函数的对象的值。

当对象是const修饰的时候，普通的 this 指针不能绑定到常量对象上，所以常量对象不能调用普通的成员函数，而常量成员函数的this指针是指向常量的指针，所以可以被常量对象调用。

总结一下：

1. 常量成员函数不能修改调用者的值
2. 常量对象不能调用普通的成员函数，只能调用常量成员函数。
